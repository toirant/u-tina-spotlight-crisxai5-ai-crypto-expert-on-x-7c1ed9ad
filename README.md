## Files

- `spotlight.png` — the graphic attached to the post
- `POST_TEXT.txt` — the exact post text
- `POST.json` — the live post's address (placeholder until posted)
- `main.ts` — copies the three deliverables to `/output/`, byte for byte
- `.makefun/owner.json` — the entrant's wallet

## Run it locally

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```

`out/POST.json`, `out/spotlight.png` and `out/POST_TEXT.txt` are then byte for byte the files in this directory. Two runs write identical bytes.
